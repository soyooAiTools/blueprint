# auto-11150ce8
## Diagnosis
`visual-check` serves the built HTML correctly but opens `/index.html` with no query params. The bridge defaults public previews to manual mode, while CUA/observe verification explicitly uses `?autoplay=1`; autoplay also requires the `__CUA_OBSERVER_READY__` handshake. Passive visual capture therefore samples a valid but undriven playable, producing identical frames across retries.

## Root Cause
`engine/stages/visual-check.cjs:177` loads `http://127.0.0.1:<port>/index.html`; `worker/linux-bridge-build.js:4295` makes manual the default unless `?autoplay=1`, and `worker/GFM_AutoPlay.cs:167` requires `__CUA_OBSERVER_READY__` before autoplay activates.
