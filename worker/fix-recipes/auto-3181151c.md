## Diagnosis
The `verifyPublicPreviewProgress` function in the upload stage navigates to the public preview URL using `waitUntil: 'load'` with a hardcoded `timeout: 45000`. Unity WebGL monolithic HTML builds are typically 20–50 MB; the browser must download the entire file and parse all inline `<script>` blocks before the `load` event fires, which easily exceeds 45 s on a loaded CDN or slow link. Every other timeout in the same function (`gameStateInitTimeoutMs=90 s`, `deadlineMs=70 s`) is already env-configurable, but the `goto` timeout is not. The subsequent `page.waitForFunction` call already covers the real engine-init wait — `waitUntil: 'load'` is therefore redundant and the source of the race.
