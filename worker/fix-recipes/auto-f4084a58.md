# auto-f4084a58
## Diagnosis
`fidelity-source-diff` captures screenshots via its own `serveSingleFile()` HTTP server. The original implementation served raw HTML/JS with no headless patching. Luna/PlayCanvas builds emit `new Event("luna:ready")` (and similar) which throw `"parameter 1 is not of type Event"` in headless Chromium before any WebGL frame is drawn, leaving a permanently black canvas. The pixel-diff gate then sees ~100% divergence on every phase (source renders, target is black), producing 23+ blocking `entity-missing` field diffs simultaneously because `extractFieldSnapshot` walks an empty PlayCanvas scene tree.

A concurrent fix (`auto-f4084a58`) wired `patchForHeadless()` into `serveSingleFile` and added `require('./lib/patch-for-headless.cjs')` — but the adapter file was not created at the same time (created 2026-06-01), so the two recorded failures occurred while the stage either crashed on load (MODULE_NOT_FOUND) or was still serving unpatched HTML. The adapter now exists and correctly extracts `.content` from the canonical `{content, fixes}` return shape. The core fix is complete.

One residual risk remains: the adapter silently falls back to returning the unpatched source if `worker-cua-verify.js` fails to load (`canonical === null`) or throws per-call — with no log entry whatsoever. The same `99.98% > 60%` failure would recur with zero diagnostic signal pointing to the degraded patcher.

## Root Cause
`engine/stages/lib/patch-for-headless.cjs:25` — `if (typeof canonical !== 'function') return source;` (and the `catch` at line 31) silently discard the patching when the canonical loader fails, masking future recurrences of the black-canvas root cause.
