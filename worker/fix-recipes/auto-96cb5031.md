# auto-96cb5031
## Diagnosis
The pre-recode guard threshold is `MAX_CUA_TOTAL_MS − RECODE_BUFFER_MS = 4 500 000 − 720 000 = 3 780 000 ms = exactly 63.000 min`. Because `Math.round(63.000) = 63` and `Math.round(63.05) = 63`, any elapsed value in the range (63.000 min, 63.5 min) renders both sides of the error message as `63min`, producing the impossible string `63min > 63min`. The guard condition itself fires correctly; only the display is wrong. Additionally, both `.env` files still carry `RECODE_BUFFER_MS=720000` even though the code has hardcoded 12 min and ignores the env var (with a warning), creating ongoing operator confusion.

## Root Cause
`engine/stages/cua-verify.cjs` line 438 (round-entry guard) and line 945 (pre-recode guard) — `Math.round(elapsed / 60000)` rounds down for elapsed values in the range (63.000, 63.500) min, making them equal to the also-rounded threshold and producing the string `63min > 63min`.
