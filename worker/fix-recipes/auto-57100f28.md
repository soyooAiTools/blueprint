# auto-57100f28

## Diagnosis
`SCHEMA_PRIMARY_BACKEND=claude-print` routes 100% of schema generation through `claude --print` with a 900 s wall-clock timeout. When the `claude` process has accumulated partial stdout during its 15-minute run, the SIGTERM kill path in `runCodexText` builds the error as `"Timed out after 900000ms; stdout: <last 500 chars of partial JSON>"` instead of `"Timed out after 900000ms; Exit code 143"`. Both `isSchemaNonRetryableError` (codegen-schema.cjs) and the FATAL_PATTERNS entry (error-classifier.cjs) require the literal suffix `; Exit code 143`, so the variant form bypasses both guards, triggering 2 internal schema-gen retries × 15 min = 30+ minutes of wasted generation per task.

## Root Cause
