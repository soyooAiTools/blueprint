## Diagnosis
`fidelity-contract-synthesize` successfully produces a v1.1.0 contract from the source HTML (PHASES + ENTITY_STYLE + SCENE_CONFIG literals), so `fidelity-source-diff.canSkip()` returns `false` and the stage runs. The target PlayCanvas/Luna build is served, but its WebGL canvas never transitions from black within the combined 60 s + 20 s readiness timeout (`FIDELITY_READY_TIMEOUT_MS` + `FIDELITY_CANVAS_BLACK_GUARD_MS`). `extractFieldSnapshot` on a black page returns an empty scene → all 18 contract entities register as `entity-missing` (blocking). `runPixelDiff` then produces ~99.99 % divergence against the rendered Three.js source across all 5 phases. The stage unconditionally throws, and since `canRetry: false`, `visual-check` (which has a 5-round AI-powered recode fix loop) is **never reached**. The task worker retries the full pipeline twice with identical deterministic failure.

## Root Cause
`engine/stages/fidelity-source-diff.cjs` **lines 338–353** — the `if (hasBlockingDiff)` throw has no guard distinguishing a *semantic fidelity regression* (partial render with wrong entities) from a *build-initialization failure* (canvas entirely black = no render at all). Both produce `hasBlockingDiff = true`, but only the former benefits from a hard block; the latter must be forwarded to `visual-check`'s recode loop for recovery.

Supporting evidence:
- Pixel divergence of **99.99 %** (not 30–70 % which would indicate cross-engine renderer noise) across **all 5 phases** simultaneously is the canonical black-canvas signature.
- 18 blocking diffs are **all entity-missing** (not entity-extra, hud-mismatch, or anchor-drift), consistent with an empty WEBGL scene snapshot, not a rendered-but-wrong scene.
- `canRetry: false` on this stage + `canRetry` absent on downstream `visual-check` means zero recovery without the fix.

## Fix
Insert a **canvas-black demote guard** in `engine/stages/fidelity-source-diff.cjs`, between the `ctx.fidelitySourceDiffReport = report;` assignment (line 336) and the `if (hasBlockingDiff)` throw (line 338). The guard fires only when **every** phase in `pixelGateFailures` shows > 95 % pixel divergence (complete-black, not partial-render). It injects a targeted `feedbackHistory` entry for `visual-check`'s recode loop and returns the report as advisory.
