# auto-f23a1abb
## Diagnosis
The `auto-3db28275` canvas-black demote guard inside `fidelity-source-diff.cjs` contains two compounding bugs that make it permanently dead code. First, it iterated `pixelGateFailures.every(...)` checking `p.pixelDiffPercent`, but those entries were pushed as `{ phase, percent, threshold }` — the correct property is `p.percent`, not `p.pixelDiffPercent` — so `typeof p.pixelDiffPercent === 'number'` is always `false` and `every()` short-circuits to `false` unconditionally. Second, even if the property name were correct, `every()` demands ALL pixel-gate-failing phases exceed the 95 % demote threshold; phases 2–4 only reach 65–90 % cross-engine spread (different shaders / AA / lighting), so `every()` would still return `false` even when phase 1 shows a clear 99 %+ black-canvas signature. The combined effect: every task whose Luna build hasn't yet rendered a WebGL frame hits a permanent hard-block, retries are burned (canRetry: false means each retry is a full pipeline restart from the outer worker loop), and visual-check's AI-powered recode loop — the intended recovery mechanism — is never reached. A secondary defect in the same block writes `ctx.feedbackHistory` instead of `ctx.blueprint.feedbackHistory`, so even if the guard were repaired, visual-check's recode AI would receive no canvas-never-rendered hint.
