## Diagnosis
`drivePageToPhase` contains two independent early-fire paths in `page.waitForFunction`.
Path A (line 543): `if (realChildren > 0) return true` fires the moment any non-scaffold
node (e.g. `GameManager`, `AudioManager`, `UIController`) attaches to `app.root` during
PlayCanvas/Luna app init — before the GPU has drawn a single pixel. Path B (line 565 and
secondary guard line 603): `|| px[3] > 0` evaluates alpha, which the WebGL spec
initialises to 255 for opaque (`alpha:false`) drawing buffers before any frame renders,
so `px[3]` is 255 immediately on context creation. Either path captures a black
uninitialized canvas, causing ~100% pixel divergence against the coloured source HTML
screenshot and an empty `visibleEntities` snapshot (WEBGL_PAGE_EXTRACTOR returns nothing
while the scene is not yet rendered) → 27+ `entity-missing` blocking field diffs.

## Root Cause

canvas-pixel confirmation, and `fidelity-source-diff.cjs:565` + `:603` include `|| px[3] > 0`
which is unconditionally true for opaque WebGL canvases before rendering begins.
