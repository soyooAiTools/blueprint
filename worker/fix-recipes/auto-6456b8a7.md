## Diagnosis
`method-check.cjs` calls `checkCompleteness(ctx.csCode)` which internally calls
`extractMethodDefinitions(csCode)` scoped to the main file only. When codegen
splits code across a partial class file (`GameFlowManagerMain.Systems.cs` in
`ctx.extraFiles`), all methods living in that file are invisible to the definition
scanner. They are flagged as "missing" even though they are correctly generated,
causing a permanent false-positive failure loop (canRetry:false → whole-task retry
→ same split output → same failure).

## Root Cause
`engine/stages/method-check.cjs:152-188` — `checkCompleteness(csCode)` passes only
`ctx.csCode` to `extractMethodDefinitions`. `ctx.extraFiles` (partial class files
written by codegen for >10-phase blueprints) is never consulted.

## Fix
Two targeted changes to `engine/stages/method-check.cjs`:

### 1. Extend `checkCompleteness` to accept combined definition source
