## 技术洞察：为什么 Linux 不需要 Luna 插件
Luna 插件做三件事：jake stage1（场景导出）、Bridge.NET（C#→JS）、jake stage4（组装）
- stage1：用预导出的 stage4-template 替代（AI 代码用 GFM_Tools 运行时创建对象，不依赖烘焙资源）
- Bridge.NET：Mono msbuild 直接跑，不需要 Unity
- stage4：linux-bridge-build.js 的 assembleStage4 函数替代
